HOW TO

잘 쓰는 법은 간단해요

요약 · 1개만 해도 참여한 날

습관 1~3개 → 끝내면 체크 → 내일 다시 열기.
빈 날이 생겨도 다음 참여는 1일부터 시작해요.

01

작아서 쉬운 행동을 적어요

‘건강해지기’보다 ‘물 한 잔’. 민감한 개인정보는 적지 마세요.

02

오늘 끝낸 일만 체크해요

한 번 더 누르면 취소돼요. 오늘 체크를 모두 취소하면 연속·최장 기록도 다시 계산해요. 과거 날짜를 소급해서 체크할 수는 없어요.

03

한국 시간 자정에 새로 시작해요

기기 시계를 기준으로 한국 시간(KST) 00:00에 오늘의 체크가 비워져요. 습관과 지난 기록은 유지돼요. 화면을 켜 둔 상태와 다시 돌아왔을 때도 날짜를 확인해요.

팁 · 3개를 다 채울 필요 없어요

기록은 평가표보다 다시 시작할 자리예요. 공유에는 날짜·개수·참여 도장만 넣고 습관명은 빼요.

주의 · 자동 동기화되지 않아요

기록은 이 브라우저의 저장소(localStorage)에만 있어요. 서버로 보내지 않지만 같은 사이트의 다른 도구는 기술적으로 접근할 수 있어요. 시크릿 모드·브라우저 데이터 삭제·기기 변경 시 사라질 수 있으니 백업을 받아 두세요.

내 기록 관리

JSON 파일로 보관해요. 가져오면 현재 기록을 덮어쓰며 확인 후 적용돼요. 내보낸 파일에는 습관명이 포함돼요.

확인 후 습관·체크·방문일을 모두 지워요. 취소하면 유지돼요. 지운 기록은 백업 없이는 복구할 수 없어요. 다른 도구의 기록은 지우지 않아요.
