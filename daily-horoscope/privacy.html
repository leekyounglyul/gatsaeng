입력과 기기 내 기록

주휴수당 계산기의 입력값은 계산을 위해 브라우저 안에서 처리하며 서버에 전송하거나 저장하지 않습니다. 생존 부적은 오늘의 추첨 결과, 방문일·연속 기록, 발견한 카드 번호를 이 기기 브라우저에 저장하며 서버로 전송하지 않습니다. 방문 기록·도감은 도구 안의 기록 초기화 버튼으로 지울 수 있습니다. 당일 추첨 결과까지 지우려면 브라우저의 사이트 데이터를 삭제하세요. 다른 도구의 저장 여부와 삭제 방법은 해당 안내를 확인하세요. 기기 내 저장을 사용하는 도구의 기록은 브라우저의 사이트 데이터 삭제로 지울 수 있습니다.

외부 글꼴과 접속 정보

Pretendard 글꼴을 표시하기 위해 jsDelivr(cdn.jsdelivr.net)에 CSS와 글꼴 파일을 요청합니다. 이때 외부 제공자에 IP 주소, 브라우저 정보 및 요청 관련 정보가 전달될 수 있습니다. 계산기에 입력한 시급과 근무시간을 글꼴 요청에 포함하지 않습니다. 글꼴 제공자의 정보 처리는 jsDelivr 개인정보처리방침을 확인하세요.

정적 페이지 제공 과정의 접속 정보 처리는 GitHub 개인정보처리방침을 따릅니다.

공유와 외부 링크

결과를 복사하거나 공유하면 선택한 입력값과 예상 금액이 공유 내용에 포함됩니다. 공유 대상과 내용을 직접 확인하세요. 외부 사이트로 이동하면 해당 사이트의 방침이 적용됩니다.
